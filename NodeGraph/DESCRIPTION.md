Describes node graphs with attributes, and nothing else. Decorate a class, struct or method with node and pin metadata — execution mode, side effects, determinism, deprecation, visibility, wildcards and custom connection rules — and any editor can read it back by reflection. Includes type-compatibility utilities that answer whether two pins may connect and whether the conversion loses information, plus a built-in library of math, string, logic, collection, date/time, control-flow and geometry nodes. Draws nothing, references no UI library, and has no dependencies at all.
