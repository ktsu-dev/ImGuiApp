Renders CommonMark markdown directly inside Dear ImGui, parsed with Markdig and extended with pipe tables, task lists and autolinks. Headings scale from the live font size, so DPI and accessibility scaling are respected automatically; links are clickable, local images resolve through a callback, and code blocks can be handed to a renderer hook that ktsu.ImGui.SyntaxHighlighting plugs into. Offers a cached static entry point and a document instance that parses once for hot render paths, with no dependency on ktsu.ImGui.App.
